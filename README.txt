Clouds Farm – Premium Website
==============================

ফোল্ডার স্ট্রাকচার:
- index.html          → মূল পেজ
- css/style.css       → সব স্টাইল (প্রিমিয়াম ডিজাইন)
- js/main.js          → ইন্টারঅ্যাকটিভিটি (ভাষা, মেনু, অ্যানিমেশন)

কীভাবে দেখবেন:
1. পুরো "clouds-farm-website" ফোল্ডারটা আপনার কম্পিউটারে ডাউনলোড/কপি করুন
2. index.html ফাইলটা ব্রাউজারে ওপেন করুন (ডাবল ক্লিক)
